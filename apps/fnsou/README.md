# 飞牛Everything(官方 fpk 直通)

[飞牛Everything](https://github.com/lilcandi/fnnas) — 类 Everything 的飞牛 NAS 本地文件搜索。

- **收录方式**:官方 fpk 直通——本仓库不打包,直接发布上游官方 fpk(字节一致)
- **上游跟踪**:上游 GitHub Release

## 说明

纯 Go 标准库单二进制实现，自带 Web UI，在飞牛桌面里以窗口打开。索引 15 万级条目约 100 秒，
搜索 2–130 ms。支持多关键词 AND、包含/全字/前缀/正则、类型与扩展名筛选、大小与修改时间筛选、
列头双向排序、缩略图网格、应用内播放/预览、CSV 导出。

首次安装后需在「应用中心 → 飞牛Everything → 设置 → 授权目录」里勾选要索引的存储空间
（飞牛默认不给应用任何用户文件访问权，这是平台机制）。
