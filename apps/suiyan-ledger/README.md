# 随言 · 记账软件

[随言记账](https://github.com/yanghy949/suiyan-ledger) 是 fnOS 原生对话记账应用，支持 Web、微信 Claw 和 QQ Bot、多账本、账单图表及 Excel 导入导出。

| 项目 | 说明 |
| --- | --- |
| 收录方式 | 上游 FPK 直通，直接分发开发者发布的原生包，保持文件字节一致 |
| 应用 ID | `com.suiyan.ledger`，与上游一致，已有安装沿用同一身份 |
| 平台 | x86；ARM 尚未发布或验证 |
| 系统 | fnOS 0.9.0 或更新版本 |
| 依赖 | 飞牛应用中心的 Python 3.12（`python312`）和 Node.js v22（`nodejs_v22`） |
| 入口 | 飞牛统一网关 `/app/com-suiyan-ledger/`，后端使用 Unix Socket，无独立 TCP 服务端口 |
| 开发者 / 发布者 | [yanghy949](https://github.com/yanghy949) |
| 许可 | MIT；第三方依赖及字体见上游许可声明 |

## 功能与首次使用

- 自然语言记账、更正、查询和图表，支持一句话多笔收支；Web 回复流式显示。
- 手动新增、筛选和批量管理流水；不同账本独立，支持对话中临时指定或切换账本。
- 微信与 QQ 授权绑定、用户备注；同一已绑定参与者可跨渠道继续会话。
- 模型服务配置、模型列表拉取、优先级与故障切换，以及助手称呼、情感和上下文设置。
- PC / 移动端自适应，动态账单图表和渠道 PNG，Excel 追加导入去重及加密聊天备份。

安装后从飞牛桌面打开应用，按引导设置应用管理员密码及模型服务的 Base URL、APIKey、模型名。管理员配置与全渠道聊天记录受到密码保护。渠道功能需另行授权，并要求设备能访问相应模型和平台服务。

账单、聊天、附件和配置保存在 fnOS 本机；对话及相关上下文会发送到用户配置的模型服务，渠道消息经过微信 / QQ 平台。模型及渠道密钥加密保存，聊天导出使用管理员密码派生密钥加密。源码和安装包不包含预置模型密钥或账号凭证。

## 分发与更新

构建契约跟踪上游最新正式 GitHub Release，并下载 `suiyan-${VERSION}-x86.fpk`。本目录仅供应用发现、展示和检查，发布流程不会把这里的配置或共享生命周期覆盖进上游包；`build.sh` 和 `cmd/service-setup` 会拒绝本地重打包。

更新请使用飞牛应用中心的正常升级流程。上游升级前创建 SQLite 备份；卸载前向应用声明的私有共享目录保存本机留存快照，重装时校验恢复。重要数据仍请主动导出备份。

当前 0.1.10 上游 FPK **未签名**，属于社区手动安装包；是否收录由本仓库维护者审核，不代表已经通过飞牛官方应用中心认证。包内保留上游的权限、依赖、桌面网关及许可文件。
